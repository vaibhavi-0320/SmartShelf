# Smart Shelf

A decentralized NFT-based book marketplace built on Ethereum that enables authors to sell unique digital copies with automated royalty distribution.

---

## 🚀 Problem

Digital books are easily pirated. Authors lose revenue due to centralized platforms and uncontrolled file sharing.

---

## 💡 Solution

Smart Shelf converts digital books into ERC-721 NFTs, enabling:

- Unique ownership
- On-chain royalty enforcement
- Transparent resale tracking
- Direct author payments

---

## 🛠 Tech Stack

- React + Vite
- TypeScript
- TailwindCSS
- Supabase
- Ethereum (ERC-721)
- Ethers.js

---

## 🔑 Features

- NFT minting
- Wallet integration
- Royalty logic
- Secure ownership verification
- Secondary resale tracking
